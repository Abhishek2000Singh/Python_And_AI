🚀 Getting Started
Prerequisites

Make sure Python is installed on your system.

Check your Python version:

python --version


or:

python3 --version

Clone the Repository
git clone https://github.com/Abhishek2000Singh/Python_And_AI.git


Move into the project directory:

cd Python_And_AI


You can then explore each folder and run the Python programs individually.
